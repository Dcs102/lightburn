This app call to home to check valid license key, 
therefore there are several options:

* Add the following lines to hosts: (C:\Windows\System32\drivers\etc)

127.0.0.1 api.cryptlex.com
127.0.0.1 raw.githubusercontent.com
127.0.0.1 lightburnsoftware.github.io


* Use a firewall to block all incoming and outgoing connections.

* You can also use it in completely offline mode (the best).
